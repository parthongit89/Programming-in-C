# C Programming - Recommended Books & Resources

Here are recommended books and reference guides for learning and reviewing C programming:

## 📚 Free Books & Resources

- **[GoalKicker - C Notes for Professionals](https://goalkicker.com/)**: Free C programming book and reference guide for quick learning and review.

## 📖 Key Topics for Review

- **Basic Syntax & I/O**: Variables, Data Types, `printf`/`scanf`, Structure of C programs.
- **Operators & Expressions**: Arithmetic, Relational, Logical, Precedence & Associativity.
- **Conditional Logic**: `if-else` statements, `switch-case`, and ternary operators.
- **Loops & Iteration**: `for`, `while`, and `do-while` loops, along with `break` and `continue`.
